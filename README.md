# LockedIn

Personal fitness tracker Android app.

## Project Structure

```
LockedIn/
├── LockedIn-server/    # Node.js/Express REST API (Phase 1)
└── LockedInApp/        # React Native / Expo app (Phase 2+)
```

## Phases

- **Phase 1** ✅ Backend & Auth Setup
- **Phase 2** App Scaffolding & Auth
- **Phase 3** Core Workout Features
- **Phase 4** Progress & Analytics
- **Phase 5** Nutrition, Calendar & Tasks
- **Phase 6** Timers & AI
- **Phase 7** Hardening, APK Build & Polish
